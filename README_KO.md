# SiMarket - 글로벌 반도체 시장 인텔리전스 대시보드 (1970–2026)

🌐 **[English (영문 설명)](README.md)** | **라이브 대시보드:** **[https://eljja.github.io/SiMarket/index_ko.html](https://eljja.github.io/SiMarket/index_ko.html)**

1970년 상업적 메모리 반도체의 탄생 시점부터 2026년 인공지능(AI) 반도체 슈퍼사이클 정점까지, 글로벌 반도체 산업의 시장 규모, 세부 세그먼트별 매출액, 리딩 기업들의 시장 점유율 변화 추이를 추적하는 인터랙티브 데이터 시각화 대시보드입니다.

## 🚀 프로젝트 개요 (이 Repo에서 한 일)

이 저장소는 다중 시장 지원 및 한/영 로컬라이징이 완료된 글로벌 반도체 시장 인텔리전스 대시보드를 제공합니다. 초기 DRAM 단일 트래커로 시작하여 현재는 다음 항목을 전방위적으로 지원하는 반도체 데이터 시각화 플랫폼으로 확장되었습니다.

* **10대 핵심 반도체 세그먼트 탑재**: 반도체 산업 전 영역을 아우르는 10가지 세부 범주 데이터를 시각화합니다.
  1. **전체 반도체** (전체 공급망 합산 달러 매출액 모델)
  2. **DRAM** (디바이스 메모리 및 HBM3E/HBM4)
  3. **플래시 메모리** (NAND & NOR 플래시)
  4. **로직 IC** (마이크로프로세서, GPU 및 독자 AI 가속기)
  5. **아날로그 반도체** (RF, 전력 관리 PMIC, Op-Amp)
  6. **광소자 및 이미지 센서 (CIS)** (모바일 카메라 센서 및 자율주행 라이다 센서)
  7. **전력 및 개별 소자** (IGBT, MOSFET 및 차세대 화합물 반도체 SiC/GaN)
  8. **MCU** (마이크로컨트롤러 8/16/32비트)
  9. **파운드리 (Foundry)** (순수 위탁 생산 파운드리 기업군)
  10. **팹리스 (Fabless)** (자체 공장 없는 반도체 설계 전문 기업군)
* **실측 달러 데이터 기반 정밀 감사 및 정합성 교정**: 주요 20여 개 선도 기업들(삼성전자, SK하이닉스, 마이크론, 엔비디아, TSMC, 인텔, AMD, 퀄컴, 브로드컴, TI, ADI, 인피니온, ST마이크로, NXP, 소니, 키옥시아, 미디어텍 등)의 분기별 재무제표 공시(SEC Filing) 수치를 기반으로 데이터를 개편하고, 7대 세부 시장의 합이 전체 시장 매출액과 소수점 둘째 자리까지 정확히 일치하도록 교정했습니다.
* **한/영 로컬라이징 병렬 설계**: 차트 툴팁, 통계 카드, 세부 마일스톤 타임라인까지 모든 UI 텍스트를 영문(`index.html` / `app.js` / `data.js`)과 국문(`index_ko.html` / `app_ko.js` / `data_ko.js`)으로 이중 현지화하여 구축했습니다.

## 🎯 핵심 전략 및 시각화 기능 (어떤 전략인지)

반도체 산업의 거시적 패러다임 변화를 한눈에 통찰할 수 있도록 정교한 UI 장치들을 배치했습니다.

* **동적 바 차트 레이스 (ECharts)**: 연도/분기 흐름에 따른 기업별 순위 및 점유율 비중 변화를 애니메이션으로 구현하여 시장 통합 및 패권 전환 과정을 추적합니다.
* **다크/라이트 테마 전환 (☀️/🌙)**: 글래스모피즘 어두운 테마와 고대비 Slate 밝은 테마 간의 자유로운 토글을 지원하며, 선택한 테마는 `localStorage`에 자동 저장되고 차트 색상 패브릭이 테마에 맞게 동적으로 적응합니다.
* **URL 딥링크 (`#market/period`)**: 카테고리 탭 및 분기별 주소 딥링크(예: `#foundry/2024_Q1`)를 지원하며 브라우저 뒤로/앞으로 가기 네비게이션이 작동합니다.
* **타임라인 정밀 조작 버튼 (`<` / `>`)**: 1분기 단위 정밀 탐색이 가능한 이전/다음 분기 컨트롤 버튼을 제공합니다.
* **이중 지표 모드 전환 (Dual-Metric)**: 매출액(달러 단위) 지표와 비트 생산량(Byte Capacity, Exabyte 단위) 및 생산 수량 지표 간의 실시간 전환을 지원합니다.
* **로그 스케일 추세 곡선 (Logarithmic Graph)**: 50년간 약 9자리(10억 배) 이상 기하급수적으로 폭증한 반도체 출하 용량 추이를 시각화 오류 없이 보기 위해 로그 스케일 축을 적용했습니다.
* **데이터베이스 압축 (JSON Minification)**: 데이터베이스 직렬화 경량화를 통해 파일 용량을 415KB에서 276KB로 약 33% 절감(~55% Gzip 절감)하여 초동 로딩 속도를 향상시켰습니다.
* **구글 SEO 최적화 및 Rich Snippets (Schema.org JSON-LD)**: 구글 검색엔진 노출을 위한 `WebApplication` 및 `Dataset` 스키마 구조화 데이터, OpenGraph 소셜 카드, `sitemap.xml`, `robots.txt`를 적용했습니다.

## 🔄 업데이트 및 실행 주기 (실행 주기가 어떤지)

이 프로젝트는 주요 글로벌 반도체 기업들의 분기별 실적 공시(Earnings Release) 주기에 맞추어 **매 분기(Quarterly) 업데이트**됩니다.

1. **원천 데이터 수정**: `scratch/generate_data.py` 파일 내에 신규 분기의 실측 매출 및 점유율 데이터를 기입합니다.
2. **데이터 컴파일 실행**: 터미널에서 데이터 컴파일러를 실행하여 경량화된 시각화용 데이터셋을 생성합니다.
   ```bash
   python scratch/generate_data.py
   ```
3. **무결성 검사**: 데이터 합산 오차 및 누락 여부를 확인합니다.
   ```bash
   node scratch/verify_data.js
   ```
4. **실시간 반영**: Git Push 실행 시 GitHub Actions가 연동되어 약 1분 이내에 `github.io` 라이브 사이트에 정적 페이지가 배포됩니다.

## 🧪 데이터 검증 모듈 작동 방식

데이터 업데이트 도중 발생할 수 있는 휴먼 에러를 방지하기 위해 터미널에서 아래 명령어를 실행하여 전수 정합성을 검증합니다.
```bash
node scratch/verify_data.js
```
해당 스크립트는 다음 항목을 체크합니다.
- **점유율 100% 합산 검증**: 각 분기별 모든 기업의 점유율 합이 100% 인지 소수점 연산 오차 판정.
- **시장 합계 검증**: 7대 메모리/로직/아날로그/광소자/전력/MCU 매출 합이 전체 반도체 시장 규모와 맞는지 검증.
- **원격지 배포 검증**: `github.io` 서버에 배포된 데이터 파일 SHA-256 해시 값과 로컬 개발 컴퓨터 파일 해시 값을 비교하여 캐시 잔존 여부 확인.
